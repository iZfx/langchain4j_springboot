关于行迹

行迹是一款全自动记录自己旅行轨迹和生活足迹的App，可为你点亮去过的每一座城市，绘制每一段旅行线路。

通过先进的GPS技术和热力图算法，我们将你的运动数据转化为可视化的美丽图案，让你更直观地了解自己的活动模式。
