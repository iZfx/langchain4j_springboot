# 自动化部署脚本使用说明

## 脚本介绍

本项目包含两个自动化部署脚本，用于简化Maven项目的构建、打包和部署流程。

### 1. build_and_package.sh (构建打包脚本)

**功能：**
- 使用Maven清理和构建项目
- 生成可执行jar包
- 创建包含部署脚本的完整部署包

**使用方法：**
```bash
./build/build_and_package.sh
```

**执行流程：**
1. 检查项目根目录和Maven环境
2. 执行 `mvn clean package -DskipTests`
3. 创建包含以下内容的zip部署包：
   - 编译生成的jar包
   - 部署脚本 (deploy.sh)
   - 应用配置文件
   - 部署说明文档

### 2. deploy.sh (部署脚本)

**功能：**
- 检查和安装JDK 17环境
- 停止已运行的应用实例
- 使用nohup后台运行应用
- 提供详细的部署状态监控

**使用方法：**
```bash
# 在部署包解压后的目录中执行
./deploy.sh
```

## 部署流程

### 开发环境构建
1. 在项目根目录执行构建脚本
2. 获取生成的部署包

### 生产环境部署
1. 将部署包传输到目标服务器
2. 解压部署包
3. 执行部署脚本

## 环境要求

### 构建环境
- JDK 8+ (用于编译)
- Maven 3.6+
- 网络连接 (下载依赖)

### 运行环境
- JDK 17+ (脚本会自动检查和安装)
- Linux/macOS系统
- 足够的系统资源 (建议4GB+内存)

## 故障排除

### 常见问题

1. **Maven构建失败**
   ```
   错误：未找到pom.xml文件
   解决：确保在项目根目录执行脚本
   ```

2. **JDK安装失败**
   ```
   错误：不支持的操作系统
   解决：手动安装JDK 17后重试
   ```

3. **端口被占用**
   ```
   警告：端口8080已被占用
   解决：停止占用进程或修改应用端口配置
   ```

4. **内存不足**
   ```
   警告：可用内存不足512MB
   解决：增加系统内存或调整JVM堆大小参数
   ```

### 日志文件位置

- 构建日志：终端输出
- 应用日志：`logs/application.log`
- GC日志：`logs/gc.log`
- 进程ID：`logs/app.pid`

## 自定义配置

可以通过修改脚本中的以下变量来自定义部署行为：

```bash
# deploy.sh 中的关键配置
PORT=8080                    # 应用端口
JVM_HEAP_SIZE="-Xmx1024m"    # JVM最大堆内存
LOG_DIR="logs"               # 日志目录
```

## 注意事项

⚠️ **生产环境建议：**
- 在生产环境中使用更严格的JVM参数
- 配置适当的监控和告警机制
- 定期备份应用数据
- 使用服务管理工具(如systemd)替代nohup

⚠️ **安全考虑：**
- 不要在生产环境使用root权限运行应用
- 配置防火墙规则限制访问
- 定期更新JDK版本修复安全漏洞
